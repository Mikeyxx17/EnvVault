# EnvVault 文档

文档按职责分为：

- [`architecture/`](./architecture/README.md)：目标架构、核心模型和模块依赖边界。
- [`security/`](./security/README.md)：威胁模型、信任边界与安全声明。
- [`roadmap/`](./roadmap/README.md)：从当前已完成基线出发的唯一后续计划。
- [`decisions/`](./decisions/README.md)：重要架构决策记录（ADR）。

设计文档必须随着实现和验证证据持续更新，不能用设计文档代替安全验收。已经完成的阶段不再保留重复路线图；历史决策通过 ADR 追踪。
