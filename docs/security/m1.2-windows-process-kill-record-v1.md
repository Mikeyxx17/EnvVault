## 5. 本机作为 VMware 客户机的第一次断电

环境：这台 Windows 10 是 VMware 客户机（`VMware20,1`，VMware Virtual NVMe）。宿主机菜单 **Power → Power Off**（不是 Guest 关机、不是 Suspend）。

- 记录：`fault-injection-runs/20260817-084850/`
- 注入点：合成 `before-manifest`
- 终止：宿主机硬关电源，然后重新开机
- 恢复：`{"verdict":"recovered","detail":"consistent state with 50 committed events"}`
- **不算窗口内断电**：看到提示后到你去点 Power Off 的这段时间里，合成场景已经把 manifest / journal / segment / descriptor / anchor / `done` 全部写完。这是「写完之后断电」，不是「写到一半断电」。

后续合成断电会在 checkpoint 处停住最多 10 分钟，必须看到提示后马上 Power Off。

第二次（`20260817-090519`）打在窗口内：

- 终止：宿主机 VMware **Power Off**（硬关）
- 重启后磁盘：仅 `checkpoints/before-manifest`（无 manifest / journal / segment / descriptor / anchor）

这是合成场景在 `before-manifest` 的一次有效断电。
